What she does

One sahayak, every sarkari need.

  • Voice-first, major Indian languages — switch mid-sentence: "मराठी में बोलो"
  • Live screen guidance — yellow highlights in an auto pop-out, always-on-top guide with live captions
  • Auto-fill mode — her inbuilt agent types the form herself, narrating each field — no screen share needed
  • Copy-ready form text — on-device profile, DigiLocker fetch (demo), share-by-link for family
  • Right portal & scheme discovery — official sites only; any govt website works day one
  • Cyber-fraud first aid — call 1930 in the golden hours, freeze the account, then file on cybercrime.gov.in
  • Photo & signature resize — to exact govt KB limits, built in
  • Safe by design — never asks OTP, Aadhaar or passwords; profile stays on device

How we built it

One browser tab ↔ Gemini Live. No backend state, no scraping.

🎙️ Citizen's browserNext.js on Vercel · mic → 16kHz PCM · screen frames only when pixels change · photoreal 3D agent lip-syncs to her live voice
🔐 Ephemeral tokensAPI key never leaves the server — browser gets single-use tokens
⇄
✨ Gemini Live (native audio)hears + sees in real time · speaks major Indian languages · Google Search fallback · auto-resumes dropped sessions
🛠️ Function calls drive the UIhighlight_region → yellow box on screen · provide_text → copy chips · open_file_tool → photo resizer

Latency engineered, not hoped for: measured configs (~3s to first word, 400ms end-of-speech VAD), echo gating, background-tab-proof capture, auto pop-out always-on-top guide with live captions.
